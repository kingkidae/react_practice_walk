# 같이 걷개 🐕

반려견과 함께하는 산책 도우미 웹앱. 공공데이터포털 오픈 API와 공공 파일데이터를 사용합니다.

| 메뉴 | 내용 | 데이터 |
| --- | --- | --- |
| 산책 지수 | 지역 대표 지점·걷기길·공원별 100점 만점 산책지수, 상세에서 점수 구성과 24시간 추천 시간대 | 기상청 단기예보, 에어코리아 대기오염·측정소, 두루누비, `cityparkdata.csv` |
| 산책로 정보 | 걷기길 경로(GPX)·출발/도착·고도 그래프, 도시공원, 반려견 동반 장소 | 두루누비, `cityparkdata.csv`, 반려동물 동반여행 |
| 내 산책 (헤더의 강아지 버튼) | 우리 강아지 프로필(견종·나이·털·단두종·알레르기)로 맞춤 산책지수, GPS 산책 기록, 달력·연속 산책일·주간 목표, 직접 기록 | (이 기기 localStorage) |
| 칼로리 계산기 | 반려견 크기·몸무게·산책 스타일 + 보호자 키·몸무게로 각자 소모 칼로리 | (계산식) |
| 병원 정보 | 내 주변 반경 / 시도·시군구별 검색, 이름 기반 진료 특징 태그, 동물약국·미용·위탁관리 탭(CSV가 있으면) | `veter.csv` 외 인허가 CSV |
| 입양하개 | 목록 → 필터 → 상세 → 찜하기, 보호소별 보호 현황, 잃어버린 아이 찾기 | 구조동물 조회 서비스 |

## 실행

```bash
npm install
npm run dev
```

`.env`

```
API_KEY=공공데이터포털 일반 인증키(Decoding)
SITE_URL=https://배포도메인   # canonical·OG·sitemap 용 (선택)
```

- 키는 Vite 서버 미들웨어(`server/publicApi.js`)에서만 쓰고 브라우저로 보내지 않습니다.
- `npm run dev` 또는 `npm run build && npm run preview` 로 실행합니다. 정적 호스팅에 올리려면 미들웨어를 서버/서버리스 함수로 옮겨야 합니다.
- `veter.csv`(동물병원)와 `cityparkdata.csv`(전국도시공원정보표준데이터)는 CP949·한글 헤더 CSV로 프로젝트 루트에 둡니다. 서버가 읽어 변환하며, 파일을 새로 받아 덮어쓰면 자동으로 다시 읽습니다.
- API 승인 상태는 `/api/status` 에서 확인할 수 있습니다.

## 참고 사항

- 두루누비 걷기길(brdDiv=DNWW)은 전국 174개, 7~26km 코리아둘레길 코스이며 대구·대전·세종·충북·제주에는 코스가 없습니다. 이 지역은 대표 지점(시청·도청) 기준 산책지수와 도시공원 산책지수(면적 큰 30곳)로 보완합니다.
- 위탁관리·미용 CSV는 개인 사업자 주소 일부가 원본에서 `***`로 가려져 있어 그대로 표시합니다. 지도 위치는 좌표로 정확히 표시됩니다.
- 동물약국 인허가에는 동물용 의약품을 함께 파는 일반 약국도 포함됩니다.
- 진드기 정보는 공공 API가 없어 월(4~11월, 5·6·9·10월 최다)과 기온(10°C 이상) 기준의 일반 안내로만 보여줍니다.
- 전남광주통합특별시는 기상청 생활·보건기상지수 지역코드가 아직 없어 자외선·꽃가루가 표시되지 않습니다.
- 2026년 행정구역 통합에 맞춰 광주광역시·전라남도는 `전남광주통합특별시`(에어코리아 시도명 `전남광주`)로 다룹니다.

## SEO

- 페이지별 `title`·`description`·canonical·Open Graph 갱신 (`src/lib/seo.js`)
- `index.html`: 키워드, OG/Twitter 카드, JSON-LD(WebApplication), `noscript` 설명, manifest
- 빌드 시 `robots.txt` 생성, `SITE_URL` 이 있으면 `sitemap.xml`(메뉴 + 걷기길 상세 174개) 생성
- 메뉴별 코드 분할과 지도 라이브러리 분리로 첫 화면 로딩 단축

## 계산식

- 산책지수: 기온(체감) 30 + 강수 25 + 미세먼지 25 + 바람 10 + 습도 10, 비·눈·미세먼지 매우 나쁨·폭염·한파 시 상한 (`src/lib/walkScore.js`)
- 보호자 칼로리: ACSM 보행/달리기 대사 방정식
- 반려견 칼로리: Taylor 외(1982) `P = 10.7·M^-0.316·v + 6.03·M^-0.303 (W/kg)` × 길 종류·산책 스타일 보정
